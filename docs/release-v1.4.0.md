# Timestamp Cam v1.4.0

- ยกเลิกการลบภาพในถังขยะอัตโนมัติ ภาพจะอยู่จนกว่าผู้ใช้จะสั่งลบถาวร
- แจ้งเตือนเมื่อพบภาพที่อยู่ในถังขยะเกิน 30 วัน พร้อมปุ่มภายหลังและเปิดถังขยะ
- เปิดหน้าหลักเมื่ออ่านต้นฉบับของภาพปกติครบ โดยไม่ต้องรอถังขยะ
- โหลดถังขยะเบื้องหลัง พร้อม animation จำนวนรูป เปอร์เซ็นต์ และแถบความคืบหน้าใน popup ถังขยะ
- เพิ่มปุ่มจัดเรียง ลากการ์ดเพื่อเปลี่ยนลำดับด้วยนิ้วหรือเมาส์ และจำลำดับหลังปิดแอป
- แสดงเลขลำดับใน popup ของภาพ และใช้ลำดับเดียวกันสำหรับดาวน์โหลดทั้งหมด
- รูปใหม่และรูปที่กู้คืนจะต่อท้ายรายการ
- เก็บภาพต้นฉบับในฐานข้อมูล Android โดยตรง พร้อมย้ายข้อมูลภาพเดิมอัตโนมัติและรักษาการตั้งค่าเดิม

ดาวน์โหลดไฟล์ `app-debug.apk` แล้วติดตั้งทับเวอร์ชันเดิมได้โดยไม่ต้องถอนแอปหรือล้างข้อมูล ตรวจสอบแล้วว่าลายเซ็นตรงกับ v1.3.2

Package: `com.example.timestamp` · Version: `1.4.0` · Version code: `10400`

การตรวจสอบ: production build และ APK build ผ่าน, Android emulator ผ่าน 8 กรณี, UI ผ่าน 9 กรณีบน desktop/mobile (ข้ามกรณีสัมผัสบน desktop 1 กรณี) ครอบคลุมภาพถังขยะเกิน 30 วัน การโหลดเบื้องหลัง การลบระหว่างโหลด การลากด้วยเมาส์/นิ้ว/คีย์บอร์ด การเลื่อนใกล้ขอบ และการจำลำดับหลังเปิดใหม่
