# Timestamp Cam v1.4.1

- ลบปุ่มและโหมดจัดเรียง สามารถจัดลำดับการ์ดจากหน้าปกติได้ทันที
- กดค้างประมาณ 0.4 วินาทีเพื่อเริ่มลาก การแตะสั้นยังเปิดภาพและการปัดเร็วเลื่อนแถบตามปกติ
- แสดงการ์ดลอยขึ้นพร้อมเงาเมื่อเริ่มลาก และมีแอนิเมชันเมื่อวางกลับ
- จำกัดการลากและจัดวางให้อยู่ในแถวเดียว ไม่มีการลากลงไปแถวล่าง
- ยังคงเลื่อนแถบอัตโนมัติเมื่อลากใกล้ขอบ และจำลำดับหลังปิด–เปิดแอป
- ป้องกัน popup ภาพเปิดขึ้นจากจังหวะปล่อยการ์ดหลังลาก

ติดตั้ง `app-debug.apk` ทับเวอร์ชันเดิมได้ โดยไม่ต้องถอนแอปหรือล้างข้อมูล

Package: `com.example.timestamp` · Version: `1.4.1` · Version code: `10401`

ตรวจสอบแล้ว: production build และ APK build ผ่าน การทดสอบ UI desktop/mobile ผ่าน 12 กรณี (ข้าม touch-only บน desktop 2 กรณี) รวมการแตะเปิดภาพ การปัดเร็ว การกดค้าง การลากแถวเดียว แอนิเมชันลอย การเลื่อนใกล้ขอบ และการจำลำดับ
